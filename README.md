# Bar Plots with Python and Seaborn

Python/Seaborn script drawing bar plots of morphometric variables, demonstrated on Mariana Trench data. Reusable scientific-plotting example.

## Scripts

- `barplot.py`

## Data

- `Tab-Morph.csv`

## Requirements

Python 3 with `matplotlib`, `pandas`, `seaborn`.

```
pip install matplotlib pandas seaborn
```
